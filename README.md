# الراعبي للتجارة — نسخة كاملة مستقلة

تحتوي هذه النسخة على كود الموقع، مصدر تطبيق أندرويد، ملفات إعداد الجداول، ومؤشرات ملفات الوسائط الـ644 (الصور، الفيديوهات، الصوت، الخطوط، PDF، وملفات التحميل) المستضافة على خدمة ملفات Lovable.

## تحميل واستيراد

تم استيراد هذا المشروع من المستودع mohamme-Mechatronics/al-raabi-power-harbor-complete. رُفعت ملفات الوسائط إلى استضافة الملفات مع الحفاظ على نفس الروابط `/__l5e/assets-v1/...`، وملفات `.asset.json` داخل `src/assets/` تشير إليها.

## تشغيل الموقع

1. ثبّت Bun.
2. نفّذ `bun install --frozen-lockfile`.
3. نفّذ `bun run dev`.

للنسخة الإنتاجية: `bun run build`. للاختبارات: `bun run test`. مصدر أندرويد وتعليماته داخل `android-app/`.

## الاستثناءات المهمة

لا تحتوي النسخة على المفاتيح السرية أو كلمات السر أو مفاتيح توقيع أندرويد، ولا على `node_modules` أو ملفات البناء المؤقتة أو سجل Git. `.env.example` يوضح أسماء الإعدادات المطلوبة دون أي قيم سرية. يجب إدخال إعداداتك الخاصة في الاستضافة الجديدة.

هذه النسخة تتضمن ملفات تعريف الجداول، لا سجلات الطلبات والإشعارات أو حسابات المستخدمين الحية: يلزم تصدير تلك البيانات بشكل منفصل. وظائف الطلبات والإشعارات والإدارة والصوت المتصل تحتاج إعداد الخدمات في الاستضافة الجديدة. لا يضمن وجود ملفات المشروع عمل تلك الخدمات تلقائياً.
